# 🚀 Sistema CRM - Gestão de Clientes e Serviços

> Sistema Full Stack de CRM desenvolvido para otimizar a gestão de clientes, controle financeiro e acompanhamento de serviços em tempo real, contando com uma interface moderna e segura.

🔗 **Acesse o projeto online:** [Ver Projeto no Render](INSIRA_O_LINK_DO_RENDER_AQUI)

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias modernas de desenvolvimento web:

* **Front-end:** HTML5, CSS3, JavaScript (Vanilla), Chart.js (Gráficos interativos)
* **Back-end & API:** Node.js / API REST
* **Autenticação & Segurança:** JSON Web Token (JWT) e Proteção por PIN para dados sensíveis
* **Banco de Dados:** PostgreSQL hospedado no [Supabase](https://supabase.com/)
* **Deploy & Hospedagem:** [Render](https://render.com/)

---

## ✨ Funcionalidades Principais

* **🔒 Autenticação Segura:** Sistema de login com geração de token JWT e controle de acesso a rotas protegidas.
* **📊 Dashboard Analítico:** Gráficos interativos construídos com *Chart.js* exibindo dados em tempo real sobre faturamento e fluxo de serviços.
* **👥 Gerenciamento de Clientes:** Módulo completo de cadastro, listagem, busca avançada e visualização de histórico detalhado.
* **💰 Controle Financeiro:** Registro automatizado de pagamentos com cálculo dinâmico de valores recebidos e pendentes.
* **🛡️ Segurança com PIN:** Camada extra de proteção para exibição de informações sensíveis dentro da aplicação.
* **🌙 UX Moderna:** Interface responsiva com suporte a modo escuro (*Dark Mode*), navegação fluida e layout intuitivo.

---

## 🗄️ Configuração do Banco de Dados (Supabase)

O sistema utiliza o **Supabase** como banco de dados relacional (PostgreSQL). As tabelas principais gerenciam:
1. **Usuários / Autenticação**
2. **Clientes**
3. **Serviços / Ordens de Serviço**
4. **Transações Financeiras**
